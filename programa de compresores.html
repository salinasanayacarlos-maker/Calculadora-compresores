2. Compresión en dos etapas con interenfriamiento

Se considera interenfriamiento ideal: el gas entra a la segunda etapa a la temperatura inicial. La presión intermedia óptima se obtiene con Pᵢ = √(P₁P₂).

La presión intermedia óptima se calcula como Pᵢ = √(P₁·P₂).

3. Compresor reciprocante

Cálculo geométrico y estimación de eficiencia volumétrica, gasto real, flujo másico y potencias. El modelo de doble efecto considera el área del vástago.

Los resultados se mostrarán con el desarrollo de las ecuaciones.

4. Compresión de mezclas de gases ideales

Procedimiento basado en el ejemplo de mezcla de las páginas 68–72 de los apuntes. Primero se calcula la temperatura final y el trabajo de compresión. Posteriormente, se obtienen las propiedades termodinámicas mediante valores exactos o interpolación lineal.

Convención de signos: W es el trabajo realizado por el gas. Durante la compresión será negativo. El trabajo suministrado por el compresor se reporta como Wentrada = −W. El balance utilizado es Q = ΔU + W.

4.3 Selección del método para las propiedades termodinámicas

Para cada gas debes obtener cuatro propiedades: u(T₁), u(T₂), s°(T₁) y s°(T₂). Selecciona individualmente si utilizarás el valor exacto de las tablas o la interpolación lineal.

Importante: Si seleccionas valor exacto, introduce directamente el valor que aparece en tus tablas. Si seleccionas interpolación, introduce las dos temperaturas tabuladas que rodean la temperatura solicitada, junto con sus respectivos valores.
